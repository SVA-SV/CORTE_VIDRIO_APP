# Corte de Vidrio - Vidriería Alex

PWA lista para GitHub Pages.

## Publicar
1. Crea un repositorio nuevo en GitHub, por ejemplo: `corte-vidrio`.
2. Sube todos los archivos de esta carpeta a la raíz del repositorio.
3. En GitHub: Settings > Pages.
4. En "Build and deployment", selecciona:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
5. Guarda.
6. GitHub mostrará la URL pública.

## En iPhone
Abre la URL en Safari > Compartir > Agregar a pantalla de inicio.

## Funciones
- cm y pulgadas
- lámina configurable
- cantidad por medida
- giro automático
- optimización por lámina
- sobrantes
- porcentaje de aprovechamiento
- guardar/cargar trabajo local
- impresión / Guardar PDF
- funcionamiento offline después de la primera carga
